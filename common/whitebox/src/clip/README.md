# whitebox.clip

Extract all the features, or parts of features, that overlap with the features of the clip vector.
Reference: https://www.whiteboxgeo.com/manual/wbt_book/available_tools/index.html#Clip

| Input | Description |
| --- | --- |
| `input_vector_file` | Input vector file. |
| `input_clip_polygon_vector_file` | Input clip polygon vector file. |
| `output_vector_file` | Output vector file. |
