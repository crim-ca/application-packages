# whitebox.costpathway

Performs cost-distance pathway analysis using a series of destination grid cells.
Reference: https://www.whiteboxgeo.com/manual/wbt_book/available_tools/index.html#CostPathway

| Input | Description |
| --- | --- |
| `input_destination_file` | Input destination raster file. |
| `input_backlink_file` | Input backlink raster file generated by the cost-distance tool. |
| `output_file` | Output cost pathway raster file. |
| `treat_zero_values_as_background` | Flag indicating whether zero values should be treated as a background. |
