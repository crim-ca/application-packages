# whitebox.power

Raises the values in grid cells of one rasters, or a constant value, by values in another raster or constant value.
Reference: https://www.whiteboxgeo.com/manual/wbt_book/available_tools/index.html#Power

| Input | Description |
| --- | --- |
| `input_file_or_constant_value` | Input raster file or constant value. |
| `input_file_or_constant_value_2` | Input raster file or constant value. |
| `output_file` | Output raster file. |
