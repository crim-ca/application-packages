# whitebox.costallocation

Identifies the source cell to which each grid cell is connected by a least-cost pathway in a cost-distance analysis.
Reference: https://www.whiteboxgeo.com/manual/wbt_book/available_tools/index.html#CostAllocation

| Input | Description |
| --- | --- |
| `input_source_file` | Input source raster file. |
| `input_backlink_file` | Input backlink raster file generated by the cost-distance tool. |
| `output_file` | Output raster file. |
